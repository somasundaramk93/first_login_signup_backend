# Login & Signup Backend API

## 🔗 Live API
https://first-login-signup-backend.vercel.app

## 📝 Description
This is a backend REST API for user authentication.
It supports user signup and login with secure password handling.

## 🚀 Features
- User Signup
- User Login
- Password hashing
- RESTful APIs
- MongoDB integration

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- JavaScript
